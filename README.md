# Orb

A real-time 2D particle sandbox. Place particles and gravity wells by click-dragging, then watch particles move under gravity, bounce off each other and the walls, and leave trails. Move wells by dragging them; change simulation speed with the time slider in the Place menu or the `[` and `]` keys. Built with C++, SDL2, and OpenGL.

Run: `make run` (requires SDL2 and SDL2_ttf; on macOS: `brew install sdl2 sdl2_ttf`).
